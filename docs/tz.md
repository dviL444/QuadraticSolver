Техническое задание

Проект «Решение квадратного уравнения»

1\. Основание для разработки

Учебный проект в рамках дисциплины «Инструментальные средстваразработки программного обеспечения».



2\. Назначение разработки

Консольное приложение для решения квадратных уравненийвида ax^2 + bx + c = 0 с вещественными коэффициентами.



3\. Требования к программе

3.1. Программа запрашивает у пользователя коэффициенты a, b, c.3.2. При a = 0 уравнение вырождается — выводится сообщение об ошибке.3.3. Программа вычисляет дискриминант D = b^2 - 4ac.3.4. Вывод результата:



при D > 0 — два корня x1 и x2;

при D = 0 — один корень;

при D < 0 — сообщение «Действительных корней нет».

4\. Требования к окружению

Операционная система: Windows 10/11

Python 3.8 или новее

5\. Этапы разработки

Проектирование структуры проекта.

Реализация модуля решения уравнения.

Реализация модуля ввода данных с проверкой.

Тестирование.
