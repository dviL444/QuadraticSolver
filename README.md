Решение квадратного уравнения

Назначение

Консольное приложение на Python для решения квадратныхуравнений вида ax^2 + bx + c = 0.



Требования к окружению

Python 3.8 или новее

Запуск

python src/main.py



Автор

Илья Двуреченский, группа ИП-3



Версия: 1.0.0

Стратегия ветвления
В проекте используется упрощённый Git Flow:

main — основная ветка, содержит стабильную версию проекта;
develop — ветка разработки, в неё попадают новые изменения и модули до включения в стабильную версию.

Обоснование: полный Git Flow (с ветками feature, release иhotfix) избыточен для небольшого учебного проекта. Однако разделение main/develop позволяет не допускать нестабильный код в основную ветку и упрощает подготовку релизов. Все новые изменения ведутся в develop, сливаются в main после проверки.
